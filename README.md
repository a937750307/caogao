# 草稿

一个极简的全屏草稿纸网页，打开即画，专注速写与随手记录。

## 功能

- **全屏画布**：画布铺满整个视口，鼠标拖动即可自由绘制。
- **只画不擦**：没有橡皮擦，保持草稿纸的纯粹——画错了就刷新。
- **刷新即重置**：刷新网页即可清空全部内容，重新开始。
- **自适应**：窗口大小变化时画布自动调整，已画内容不丢失。
- **渐隐提示**：页面顶部循环显示「草稿纸 · 只能画，没有橡皮擦 · 刷新网页即重置」。

## 使用方法

1. 用浏览器直接打开 `index.html`，或部署到任意静态托管平台。
2. 在画布上按住鼠标拖动即可绘制。
3. 需要清空画面时，刷新页面即可重置。

## 技术说明

- 纯原生 HTML + CSS + JavaScript，无任何依赖，单文件即可运行。
- 使用 Pointer Events 支持鼠标与触控。
- 使用 `ResizeObserver` 实现画布自适应，缩放时保留已有内容。
- 坐标通过 `getBoundingClientRect()` 换算，保证画线位置与指针严格对齐。

## 底部备案

页面底部包含 ICP 备案与公安备案信息，移动端自动切换为竖向布局。
